详细数据

范围与数量

武器与强化共 153 个类型、687 条等级配置，其中 26 个被动强化、40 个进化类型。49 个类型带特殊获取标记，39 个类型带永久隐藏标记，分类之间可以重叠。

怪物共 579 个类型，每个类型在当前本体 JSON 中只有一条基础配置。180 个类型标记为图鉴收录，70 个类型使用 BOSS 前缀 ID；“BOSS 前缀”只是筛选条件，不等同于完整的 Boss 行为分类。

地图共 24 个关卡配置、535 条逐分钟配置。17 个关卡声明循环图块，2 个关卡带详细地图图片。地图详情同时包含图标、背景、图块、模式修正、敌群与解锁数据。

数值口径

所有数值均来自原始配置，不等于加入角色、被动、Arcana、难度和局内修正后的最终结果。空白显示为“—”，它与显式配置的 0 不同。

武器后续等级是升级补丁，已验证 DataHelper.UpgradeJsonData 对数值字段执行加法。页面和 weapons.csv 按数组顺序累计合并，非数值字段替换；weapon-level-patches.csv 保留未合并的原始补丁。

武器的 interval、duration、repeatInterval 和 hitBoxDelay 以毫秒数值展示，例如 1350 表示 1.35 秒。power、maxHp、speed、area 等字段保留游戏自己的数值尺度，不擅自换算成最终伤害或移动单位。

图片与详情

图片由 Unity Sprite 资源按“图集名称 + 帧名”提取，153 个武器/强化和 579 个怪物全部匹配成功。页面展示原始 PNG 并以像素方式放大，怪物选择其 frameNames 的第一帧。

武器详情提供等级切换、核心成长表和全部原始字段；怪物详情提供技能、抗性、出现关卡、图鉴变体和全部原始字段。
